# DY-FullScreen

独立版抖音全屏 Theos 插件。

来源：从 `xiaoye-debug/DYYY` 的全屏逻辑中独立整理，并保留已经修复的「作品主页上下作品重叠」修复。

## 当前包含

- 首页/视频流全屏高度扩展
- 作品详情页全屏高度扩展
- 作品主页分页兼容
- 作品主页图片 Cell 防止重复累计位移
- 底部 TabBar 背景隐藏
- 播放进度/底部区域透明化
- 图文/横屏入口相关位置修正
- 直播预览页底部控件上移与缩放逻辑
- 不依赖 DYYY 设置页面，注入后直接启用

目标 Bundle ID：`com.ss.iphone.ugc.Aweme`
